# 課題0502 && と != の組み合わせ

入力された int 整数が **10 以上 15 未満かつ 12 以外** のとき「OK」，そうでないとき「NG」と表示するプログラム `main.c` を完成させよ．

## もう1つの課題: 条件を言葉と数で確かめる
-5 から 20 までの整数のうち，**OK と表示される整数を全部** `answer.txt` に書け(空白または改行で区切る)．
プログラムを書いてから，実際に動かして確かめてよい．

## 提出するファイル
- `main.c`
- `answer.txt` : OKになる整数の一覧
- `ai_log.txt`

## 採点について
- push すると GitHub Actions が自動採点します。結果は Actions のログと、フィードバック用の Pull Request に出ます。
- 採点は **プログラムを実行した結果** で行います。何度でも push して再採点できます。
- `ai_log.txt`(AI利用ログ)も採点対象です(10点)。AIを使ってもかまいません。ただし **AIの答えを自分で確かめること** が課題の目的です。
